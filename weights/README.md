# Model Weights Directory

This directory stores the trained classification weights and evaluation artifacts generated by `train.py`:

- `best.pt`: The optimal checkpoint saved during training with highest validation accuracy.
- `confusion_matrix.png`: High-resolution visual confusion matrix heatmap generated during evaluation on `Brain_tumor_dataset/content/Testing`.
- `evaluation_report.json`: Comprehensive quantitative metrics (Top-1 Accuracy, Macro/Per-class Precision, Recall, and F1-score).

To train the model and populate this directory, execute:
```bash
python train.py --epochs 30 --batch 16 --imgsz 224 --patience 10
```
